## 🔍 About The Project

This project archives the decision-making process and reasoning behind financial market analysis for gold (GC=F) and potentially other assets. The goal is to document the **logical flow**, **market structure identification**, and **strategic conclusions** derived from technical analysis, without exposing the raw algorithmic signals.

### Key Features
- **Narrative Reasoning**: Focus on the *why* and *how* of market interpretation.
- **Sanitized Data**: Technical indicators are abstracted (e.g., `METRIC_14`, `AI_AGENT`) to focus on the reasoning pattern rather than the specific tool.
- **Educational Value**: Demonstrates the synthesis of multiple timeframe analyses (1H, 4H, 6H) into a coherent strategy.
