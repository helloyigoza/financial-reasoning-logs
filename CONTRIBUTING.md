# Contributing to Financial Reasoning Logs

Thank you for your interest in contributing to this project! We welcome contributions that improve the quality of financial analysis documentation and reasoning clarity.

## How to Contribute

1. **Fork the Repository**: Create your own copy of the project.
2. **Create a Branch**: `git checkout -b feature/AmazingAnalysis`
3. **Commit Your Changes**: `git commit -m 'Add some AmazingAnalysis'`
4. **Push to the Branch**: `git push origin feature/AmazingAnalysis`
5. **Open a Pull Request**

## Guidelines for Analysis Reports

When submitting a new analysis log (markdown file inside `analyses/`), please adhere to the following structure:

- **Filename**: `YYYY-MM-DD_Asset_Type.md` (e.g., `2026-02-09_BTC_Analysis.md`)
- **Language**: English (required for all public reports).
- **Sanitization**: Ensure **NO** specific proprietary indicators or AI tool names are present. Use generic terms like `METRIC_01` or `AI_AGENT`.
- **Focus**: Emphasize the *reasoning* and *interpretation* of market structure, not just raw signals.

## Code of Conduct

Please be respectful and constructive in your contributions and feedback.
